Design and implement an AI chat interface with tool calls and human approvals.

The product lets a user ask an AI agent to inspect files, run commands, edit content, and create tasks. Tool calls must be visible and understandable before they execute.

Required content:

- A conversation with user, assistant, and tool-call messages.
- At least two pending approval states.
- Clear approve, reject, and inspect affordances.
- A side panel or equivalent context area showing what the agent is about to do.
- Responsive behavior for mobile and desktop.

The interface should create trust without making the workflow slow.
