Design and implement a mobile screen for a habit-tracking app.

The user opens the app daily to check progress, complete habits, edit today's plan, and understand streaks without feeling overwhelmed.

Required content:

- A mobile-first layout.
- Today's habits with completion controls.
- Streak or progress context.
- A way to edit or add a habit.
- A tone that supports consistency without guilt.

The result should still render well in a desktop browser, but the primary design target is mobile.
