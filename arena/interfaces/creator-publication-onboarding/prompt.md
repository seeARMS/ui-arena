Design and implement an onboarding flow for a creator starting a publication.

The creator needs to name the publication, define its audience, choose a cadence, set up basic branding, and publish a first draft or welcome note.

Required content:

- A multi-step progress structure.
- Inputs and selections that feel specific to publications.
- Useful defaults and examples.
- A confirmation or preview state.
- Responsive behavior for mobile and desktop.

The flow should feel quick but not flimsy.
