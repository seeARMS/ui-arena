Design and implement a route planner for cyclists and runners.

The user wants to compare possible routes before heading outside. The interface should help them understand distance, elevation, surface, estimated time, weather, and safety tradeoffs.

Required content:

- A map-like route visualization or strong substitute if no map tiles are used.
- Route comparison controls.
- Distance, elevation, weather, and pace information.
- A way to switch between cycling and running.
- Responsive behavior for mobile and desktop.

Do not use external map services or remote assets. Build a self-contained representation.
