Design and implement an admin table for managing API keys and permissions.

The user is an engineering admin who needs to see owners, scopes, last-used timestamps, expiration dates, rotation health, and risky keys.

Required content:

- A dense but readable table.
- Filters, search, or segmented controls.
- Permission scopes and owner information.
- Warning states for stale, over-scoped, or expiring keys.
- Row actions for rotate, revoke, and inspect.
- Responsive behavior for smaller screens.

Prioritize clarity and operational confidence.
