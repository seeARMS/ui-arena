Design and implement a pricing page for an AI coding assistant.

The product helps developers plan changes, edit code, run tests, and review pull requests with an AI agent. The pricing page should help an individual developer understand the entry plan, help a growing engineering team compare usage limits, and give larger organizations a clear path to contact sales.

Required content:

- Three paid plans with realistic prices and usage limits.
- A clear team upgrade path.
- Trust signals for security, privacy, and source-code handling.
- FAQs that answer practical buying objections.
- Responsive behavior for mobile, tablet, and desktop.
- Strong visual hierarchy that makes the recommended plan obvious without hiding tradeoffs.

Do not build a generic SaaS template. Make the page feel specific to an AI coding assistant.
